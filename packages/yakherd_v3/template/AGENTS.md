# Agent instructions

Read `SSOT.md`, `BASELINE.md` and `NOW.md`, then only the source, tests, configs
and linked technical material needed for the current objective. `SSOT.md`
owns the operating rules; this file is the agent entry point.

- One implementation task is the default. Ordinary authorized reversible
  local work proceeds directly to code, tests and measured results.
- Keep one integration writer and one task-owned local compute pipeline.
- Preserve current human authority, existing work, evidence and uncertainty.
- Architecture or independent review serves a concrete technical need; no
  mandatory team startup, waiting roles, bootstrap gate or review ledger.
- Update the actual owner. Historical prompts, plans, reviews and status
  logs are evidence, not current instructions.
- Follow the evidence, process hygiene, Git and milestone rules in `SSOT.md`.
- Continue the authorized next action until done or genuinely blocked. A
  completed plan is not completed implementation.

On Windows, follow the finite execution and ownership rules in
[.yakherd/policies/Y-PROC-1.md](.yakherd/policies/Y-PROC-1.md).
A request to "Start Yakherd" means read [START_HERE.md](START_HERE.md) and
continue the current objective in this task. It does not launch a role roster.
