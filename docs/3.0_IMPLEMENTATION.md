## Accepted scope and completion

- Make the compact AGENTS/SSOT/BASELINE/NOW/README process the actual setup
  default, with an optional agent adapter, direct startup and process policy.
- Standard-library-only runtime; no installer network, dependency installation,
  product execution, automation, or target Git operations.
- Fail-closed no-overwrite setup; read-only structural diagnostics that never
  execute target scripts or claim product correctness.
- Reviewed, exact-state migrations using prepared project-specific files,
  an allowlist, before/after hashes, transactional replacement and retained
  backups/recovery information. Preserve product content and real hazards.
- Consistent CLI, source templates, documentation, package metadata 3.0.0,
  build/CI verification and meaningful security/regression tests.
- Validate fresh setup, changed-project diagnostics, migration drift/containment/
  recovery, wheel/sdist installation, Windows/Linux CI and independent review.
- Commit only intentional release files, push without rewriting history and
  verify public GitHub state. Prepare a local migration inventory; bulk target
  rewrites are a follow-on after per-project inspection and migration review.

Write boundary: this isolated Yakherd checkout's source, new v3 package, tests,
docs, metadata and workflows. Retain the historical V1 package for provenance
and regression checks. No product-repository writes, target executions, paid
services, credentials disclosure or unrelated changes. The original checkout
and its unfinished 1.5 work remain intact.

The v3 engine reuses the existing transactional writer and extends it with
