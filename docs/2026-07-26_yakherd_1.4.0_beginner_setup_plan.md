## Goal

Make the ordinary beginner journey exactly:

```text
python -m pip install --upgrade yakherd
cd <project>
yakherd setup
```

Setup must inspect the real target before choosing behavior, never infer
retrofit merely because a directory exists, verify a successful installation,
and end with the plain Codex handoff `Start Yakherd`.

## Accepted Requirements

1. `yakherd` with no arguments is non-mutating and prints a short,
   state-aware next step instead of the low-level help catalogue.
2. `yakherd setup [PATH]` defaults to the current directory, derives the
   project name from the target directory, and permits explicit overrides.
3. A nonexistent, empty, or nonempty target with no Yakherd payload-path
   collisions receives a transactional no-overwrite fresh installation.
4. Unrelated existing files remain byte-identical. Any payload-path collision,
   case alias, reparse/symlink boundary, invalid target, or race fails before
   overwrite and reports that setup did not complete.
5. An existing Yakherd receipt makes setup idempotent: validate the current
   installation and do not reinstall.
6. `yakherd doctor [PATH]` is read-only, requires a valid install receipt, runs
   the installed strict protocol and Governor-policy validators, and reports
   one ready/not-ready result.
7. Successful setup runs doctor automatically and prints the next Codex prompt
   `Start Yakherd`.
8. Installed `AGENTS.md`, `START_HERE.md`, and README treat the human phrase
   `Start Yakherd` as explicit launcher invocation; it does not itself grant
   Git, network, product, or release authority.
9. `init`, `retrofit`, `exec`, `process`, and `package-help` remain available;
   low-level fresh/retrofit safety properties remain intact.
10. Release 1.4.0 includes the already implemented canonical-equivalence
    disposition, with real hazards and all other P0/P1 findings still blocking.
11. PyPI project metadata, package metadata, manifest, release bindings, tag,
    commit, GitHub release, and published version agree on `1.4.0`.

## Implementation

1. Relax only the blanket nonempty-target rejection in fresh preflight. Keep
   per-destination exclusive creation, complete collision checks, containment,
   reparse rejection, transaction cleanup, and race checks.
2. Add a small high-level setup/doctor adapter around the reviewed installer.
   Keep the installer dependency-free and prohibit network, Git, product, and
   coding-client automation.
3. Make help and success output concise and outcome-oriented.
4. Add adversarial tests for additive installation, collision failure,
   idempotence, derived names, doctor failure, no-argument behavior, and the
   exact `Start Yakherd` handoff.
5. Update beginner documentation and release smoke tests to use the primary
   setup/doctor path while retaining low-level compatibility coverage.
6. Set all version owners to 1.4.0, regenerate manifest/release hashes, and
   build exact wheel/source archives.
